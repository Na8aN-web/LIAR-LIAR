## Audio

Music and ambience files live in `assets/source/audio/` (never modified). `pnpm audio` trims,
re-encodes and loudness-normalises them into `apps/web/public/audio/`. The files carry no
metadata (no title, artist or license tags), so the source and license of each must be filled in
by whoever downloaded them.

| File | Used for | Web copy | Source URL | License |
| --- | --- | --- | --- | --- |
| `westernmusic.mp3` (108 s) | Music: menu and lobby, quieter while searching, under the tension layer | `music-westernmusic.mp3`, 128 kbps | _to fill in_ | _to fill in_ |
| `victory.mp3` (139 s) | Victory song: plays once, quietly, when a game ends | `victory-victory.mp3`, 128 kbps | _to fill in_ | _to fill in_ |
| `fire.mp3` (594 s) | Campfire crackle loop (a 60 s cut) | `fire-fire.mp3`, 64 kbps mono | _to fill in_ | _to fill in_ |
| `wind.mp3` (43 s) | Wind loop | `wind-wind.mp3`, 64 kbps mono | _to fill in_ | _to fill in_ |
| `crow.mp3` (11 s) | Distant crows, now and then | `crows-crow.mp3`, 64 kbps mono | _to fill in_ | _to fill in_ |

**Sound effects are original:** every UI sound (wooden knock, telegraph clicks, bell, crow
caw, paper slap and stings, clock ticks, stamp, coins, victory and despair stings, cloth
rustle, game-end phrase) and the tension drone are synthesized in code with the Web Audio API
(`apps/web/lib/audio/`). No samples, nothing to license.

## Tools

- [glTF-Transform](https://gltf-transform.dev) and [meshoptimizer](https://github.com/zeux/meshoptimizer) (MIT): model optimization and compression
- [FBX2glTF](https://github.com/facebookincubator/FBX2glTF) (BSD): FBX conversion
- [sharp](https://sharp.pixelplumbing.com) (Apache 2.0): texture compression
- [FFmpeg](https://ffmpeg.org) via [ffmpeg-static](https://github.com/eugeneware/ffmpeg-static) (LGPL/GPL; build tool only, not shipped): audio trimming and encoding
- [Playwright](https://playwright.dev) (Apache 2.0; dev tool only): How to Play screenshots
